# Experiment results index

All result files are retained intentionally. They record different experiments, attack configurations, and stages of this RSA research; do not treat similarly named files as interchangeable.

## Fermat

| File | Description |
| --- | --- |
| `fermat.csv`, `fermat.png` | Original 2048-bit prime-gap sweep |
| `fermat_refined.csv`, `fermat_refined.png` | Refined 2048-bit Fermat transition, with exact check counts |
| `fermat_scaling.csv`, `fermat_scaling.png` | 2048/3072/4096-bit comparison with gap sizes normalised to modulus_bits/4 |

The original/refined benchmarks may use a different iteration limit from the scaling benchmark, so do not directly compare success percentages without accounting for the cap.

## Preserving reproducibility

Raw per-trial CSV files are the primary experimental evidence. Charts are derived outputs. Avoid deleting either until results and report figures have been finalized.

Every result should be interpreted together with its runner's parameter settings, modulus size, trial count, iteration cap or lattice parameters, and the machine/SageMath version.
